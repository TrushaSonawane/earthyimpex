EARTHY IMPEX — GITHUB PAGES PACKAGE

This package matches the flat file layout in the earthyimpex GitHub repository.

UPDATE YOUR REPOSITORY
1. Extract this ZIP on your computer.
2. Open the earthyimpex repository on GitHub and choose Add file > Upload files.
3. Select all extracted files and upload them into the repository root (do not upload the ZIP itself or create another folder).
4. Review that index.html, site.css, site.js, the image/PDF files, favicon.svg and CNAME appear at the top level, then commit the changes to main.
5. GitHub Pages will publish the updated files after the commit.

The CNAME file is set to www.earthyimpex.com. Keep the existing GoDaddy email/MX records unchanged.
